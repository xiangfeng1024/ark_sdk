# MaixCam Pro 花盆与循迹校准协议

MaixCam Pro屏幕侧边串口使用`/dev/ttyS0`、115200、8N1。STM32F103使用USART2 PA3接收、PA2发送。所有多字节整数均为小端。

## 帧格式

所有请求和响应都使用同一可变长帧：

| 字段 | 长度 | 说明 |
|---|---:|---|
| header | 2 | 固定`0x5A 0x5B` |
| len | 1 | 从第一个包头到包尾的总长度 |
| command | 1 | 命令字 |
| payload | N | 命令数据 |
| tail | 1 | 固定`0xA5` |

STM32响应的payload第一个字节固定为状态：`0`成功、`1`未发现有效Flash记录并返回默认参数、`2`执行失败。

## 命令

### 命令1：花盆目标

相机到STM32，固定14字节。payload为以下结构：

```c
struct maixcam_flower_payload {
    uint8_t flags;      // bit0=1表示检测到目标
    uint16_t center_x;
    uint16_t center_y;
    uint16_t width;
    uint16_t height;
};
```

未检测到目标时flags和四个几何字段均为0。

### 命令2：采集白色区域

相机发送5字节空payload请求。STM32采集8路ADC38原始值，立即更新运行时白色标定，并返回状态加`uint16_t white[8]`，响应总长22字节。

### 命令3：采集黑色区域

相机发送5字节空payload请求。STM32采集8路ADC38原始值，立即更新运行时黑色标定，并返回状态加`uint16_t black[8]`，响应总长22字节。

### 命令4：写入内部Flash

STM32只在本轮白色、黑色都成功采集后写入当前标定，否则返回状态2。成功时返回6字节状态响应。记录包含magic、版本、结构长度、白/黑数组和CRC32。

### 命令5：读取内部Flash

STM32读取并应用内部Flash标定，返回状态加`white[8]`和`black[8]`，响应总长38字节。Flash为空、magic/版本/长度错误或CRC32失败时，状态为1并返回编译期默认参数。

### 命令6：启动业务任务

相机发送5字节空payload请求。STM32仅在循迹业务处于`STOPPED`或`FAULT`时接受，执行统一的业务状态机初始化并返回6字节状态响应；业务已运行时返回状态2且不重启状态机。成功响应立即返回，但底盘保持停车1秒后才进入循迹，防止按键确认后车辆立即动作。

MaixPy启动后先等待相机稳定10秒，随后停留在启动页。用户按下“启动任务”按钮后，相机发送命令6并进入正常花盆识别；进入或退出循迹校准不会自动启动小车。

### 命令7：任务可启动通知

STM32到相机，使用6字节状态帧，状态固定为0。STM32处于`STOPPED`或`FAULT`期间每1秒持续广播该通知，直到收到并接受命令6，不再把一次UART写成功视为相机已确认。相机锁存任务就绪状态，进入花盆识别页面后在右上角FPS下方显示“启动任务”按钮，并在先前SAVE关闭触摸线程后重新启动触摸读取；只有命令6成功响应才清除锁存状态。因而通知提前到达或单帧丢失都不会导致按钮永久缺失。

## 内部Flash布局

STM32F103C8最后一个物理擦除页为1KB，地址`0x0800FC00..0x0800FFFF`。链接器IROM长度缩小为`0xFC00`，确保程序不会进入该页。参数逻辑区域使用最后512字节`0x0800FE00..0x0800FFFF`；写入时必须擦除所属的完整1KB页。
