# example 组件用户开发指南

## 1. 组件定位

说明组件解决的问题、适用硬件或协议、依赖的 HAL/stream/其它组件，以及不负责的边界。

## 2. DTS 配置

```dts
example {
    compatible = "example";
    status = "okay";
};
```

| 属性 | 必填 | 类型/单位 | 说明 |
|---|---|---|---|
| `compatible` | 是 | 字符串 | 固定为 `"example"`。 |
| `status` | 否 | 字符串 | 缺省或 `"okay"` 启用，`"disabled"` 禁用。 |

配置完成后执行：

```powershell
python -m studio.cli dts app/<app> --check
python -m studio.cli dts app/<app>
```

## 3. API 参考

| API | 作用 | 成功条件/返回值 |
|---|---|---|
| `bool example_register(void)` | 向组件框架注册组件；不访问硬件。 | 注册成功返回 `true`。 |

## 4. 使用流程

1. 在 App DTS 中加入组件节点并完成资源绑定。
2. 运行 DTS 检查和生成器，不手工修改生成文件。
3. 由 `ark_dts_register_components()` 注册，再由统一启动流程执行 `init` 和 `self_test`。
4. 仅在组件初始化成功后调用业务 API，并处理所有失败返回值。

## 5. 注意事项

- 列出硬件接线、地址、波特率、单位、超时、线程/ISR、缓冲区和资源冲突要求。
- 公共 API 不接收 CubeMX 句柄；UART 协议必须通过 `ark_stream`。

## 6. 验证

```powershell
python -m studio.cli dts app/<app> --check
python -m pytest studio/tests -q
```

补充目标板自检、CLI 命令、总线抓包或示波器验证方法。
