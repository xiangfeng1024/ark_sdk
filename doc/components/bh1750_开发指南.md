# bh1750 组件用户开发指南

## 1. 组件定位

BH1750 环境光传感器驱动，经 `ark_hal_i2c` 读取照度，输出 `lux_x10`（0.1 lux）和 tick。

## 2. DTS 配置

```dts
i2c1: i2c1 {
    compatible = "ark_hal_i2c";
    bh1750@23 {
        compatible = "bh1750";
        reg = <0x23>;
        status = "okay";
    };
};
```

| 属性 | 必填 | 类型/单位 | 说明 |
|---|---|---|---|
| `compatible` | 是 | 字符串 | 固定为 `"bh1750"`。 |
| `reg` | 是 | 7 位 I2C 地址 | 当前驱动只支持 `0x23`。 |
| `status` | 否 | 字符串 | 控制组件是否启用。 |

节点必须位于 I2C provider 下；使用 ADDR 高电平地址 `0x5c` 前必须先扩展驱动。

配置完成后执行 DTS 校验和生成：

```powershell
../ark_stdio_rust/ark-studio-cli.exe dts.check --input doc/examples/dts-参数.json
../ark_stdio_rust/ark-studio-cli.exe dts.generate --input doc/examples/dts-参数.json
```

## 3. API 参考

| API | 作用 |
|---|---|
| `bh1750_register()` | 注册组件和诊断 CLI。 |
| `bh1750_read(sample)` | 触发/读取照度并输出 0.1 lux 单位快照。 |

## 4. 使用流程

配置 I2C provider 与地址，生成 DTS；框架自检通过后按业务周期调用 `bh1750_read()`。

## 5. 注意事项

- ADDR 引脚接法必须与地址一致；SCL/SDA 需要合适上拉。
- 不得绕过 I2C HAL 互斥直接调用厂商 HAL。
- 读取失败时不要使用未更新的输出结构。

## 6. 验证

运行 DTS/pytest 检查和 BH1750 CLI；遮挡与强光变化时确认 `lux_x10` 单调响应，并检查 I2C ACK。
