# icm20602 组件用户开发指南

## 1. 组件定位

ICM20602 六轴 IMU 驱动，提供原始/工程量采样、零偏校准、姿态更新、数据就绪等待和诊断；依赖 `i2c`、`gpio` HAL。

## 2. DTS 配置

```dts
i2c1: i2c1 {
    compatible = "ark_hal_i2c";
    icm20602@68 {
        compatible = "icm20602";
        reg = <0x68>;
        int-gpios = <&gpiob 0 0>;
        status = "okay";
    };
};
```

| 属性 | 必填 | 类型/单位 | 说明 |
|---|---|---|---|
| `compatible` | 是 | 字符串 | 固定为 `"icm20602"`。 |
| `reg` | 是 | 7 位 I2C 地址 | 仅允许 `0x68` 或 `0x69`。 |
| `int-gpios` | 是 | GPIO phandle | 数据就绪中断脚。 |
| `status` | 否 | 字符串 | 控制组件是否启用。 |

节点必须位于 I2C provider 下。

配置完成后执行 DTS 校验和生成：

```powershell
../ark_stdio_rust/ark-studio-cli.exe dts.check --input doc/examples/dts-参数.json
../ark_stdio_rust/ark-studio-cli.exe dts.generate --input doc/examples/dts-参数.json
```

## 3. API 参考

| API | 作用 |
|---|---|
| `icm20602_register()` | 注册组件和扫描 CLI。 |
| `icm20602_wait_data_ready(timeout_ms)` | 等待中断通知，超时返回 `false`。 |
| `icm20602_read_sample()` | 读取一次未经姿态滤波的原始/工程量样本。 |
| `icm20602_calibrate()` | 采集静止零偏并更新校准状态。 |
| `icm20602_update()` | 读取并更新姿态、角速度和角加速度。 |
| `icm20602_get_motion()` | 复制最新运动与姿态快照。 |
| `icm20602_get_diagnostics()` | 复制 WHO_AM_I、中断、采样、超时和总线恢复计数。 |
| `icm20602_scan()` | 扫描地址和关键寄存器并输出诊断。 |

## 4. 使用流程

确认地址/中断接线后初始化，静止执行校准；若内部任务已启用，应用只读取 motion 快照，否则按固定周期 wait/update。

## 5. 注意事项

- 校准期间器件必须静止；震动会污染 gyro bias。
- ISR 只通知任务，不做 I2C；总线访问必须经 HAL 互斥。
- `temperature_cdeg`、`gyro_mdps`、`euler_cdeg` 均使用带单位整数，避免误当浮点度数。

## 6. 验证

检查 WHO_AM_I、IRQ 计数和超时计数；静止时观察零偏和姿态漂移，分别绕三轴旋转确认方向与量纲。
