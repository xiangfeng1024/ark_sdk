# ws2812b 组件用户开发指南

## 1. 组件定位

WS2812B RGB 灯链组件，最多 8 颗，颜色输入为 RGB、线上顺序为 GRB，支持 PWM DMA 或 GPIO 软件时序；依赖 `gpio`、`pwm`、`time` HAL。

## 2. DTS 配置

软件时序：

```dts
ws2812b {
    compatible = "ws2812b";
    data-gpios = <&gpioa 7 0>;
    ark,transport = "software";
    chain-length = <8>;
    status = "okay";
};
```

| 属性 | 必填 | 类型/单位 | 说明 |
|---|---|---|---|
| `compatible` | 是 | 字符串 | 固定为 `"ws2812b"`。 |
| `ark,transport` | 是 | 枚举字符串 | `"software"` 或 `"pwm-dma"`。 |
| `chain-length` | 是 | 灯珠数量 | 1..`WS2812B_MAX_COUNT`。 |
| `data-gpios` | 软件模式 | GPIO phandle | 软件时序输出脚。 |
| `pwms` | PWM 模式 | PWM phandle | 硬件 PWM/DMA provider。 |
| `status` | 否 | 字符串 | 控制组件是否启用。 |

只配置所选 transport 需要的资源。

配置完成后执行 DTS 校验和生成：

```powershell
python -m studio.cli dts app/<app> --check
python -m studio.cli dts app/<app>
```

## 3. API 参考

| API | 作用 |
|---|---|
| `ws2812b_register()` | 注册灯链组件。 |
| `ws2812b_init()` | 加载 transport、灯数和缓冲配置。 |
| `ws2812b_self_test()` | 执行有界灯链自检。 |
| `ws2812b_count()` | 返回 DTS 配置灯数。 |
| `ws2812b_write(colors, count)` | 写入整组颜色并提交。 |
| `ws2812b_fill(r,g,b)` | 全链填充同一颜色并提交。 |
| `ws2812b_off()` | 清零并提交，关闭全链。 |
| `ws2812b_set(index,r,g,b)` | 修改内存中的单颗颜色。 |
| `ws2812b_show()` | 提交当前颜色缓存。 |
| `ws2812b_clear()` | 仅清空内存颜色缓存。 |

## 4. 使用流程

选择 transport 并检查 DMA 资源；初始化后可直接 write/fill，或多次 set 后一次 show；停止时 off。

## 5. 注意事项

- 800 kHz 波形对时序敏感，软件模式发送期间应控制中断抖动。
- 大量灯珠需要独立 5 V 电源、共地和足够电流；数据电平可能需要转换。
- STM32F1 TIM3_CH4 PWM DMA 与 SPI1 TX 可能共用 DMA1 Channel 3，必须避免冲突。

## 6. 验证

依次显示红、绿、蓝、白、熄灭和逐灯序列；用逻辑分析仪检查 GRB 位序、800 kHz 波形和 reset 低电平时间。
